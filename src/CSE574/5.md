# Lecture 5: Hierarchy Theorems and Ladner's Theorem

**Main point:** more resources → more power; P ≠ NP → NP-intermediate problems

## Constructible bounds

**Purpose:** enforceable simulation limits

The simulator must track its budget within that budget. Otherwise, the clock or memory bookkeeping could cost more than the resource bound being proved.

- **Time-constructible $t(n)\geq n$:** on input $1^n$, produce $1^{t(n)}$ in $O(t(n))$ time
- **Space-constructible $s(n)\geq\log n$:** mark off $s(n)$ work cells using $O(s(n))$ space
- **Little-o:** $f=o(g)$ means $f(n)/g(n)\to0$

**Examples:** standard integer-rounded polynomial and exponential bounds

## Three hierarchy theorems

**Assumptions:** constructible bounds; $t_1,t_2\geq n$; $s_1,s_2\geq\log n$

| Resource | Required gap | Conclusion |
| --- | --- | --- |
| Deterministic time | $t_1(n)\log t_1(n)=o(t_2(n))$ | $\mathrm{DTIME}(t_1)\subsetneq\mathrm{DTIME}(t_2)$ |
| Nondeterministic time | $t_1(n+1)=o(t_2(n))$ | $\mathrm{NTIME}(t_1)\subsetneq\mathrm{NTIME}(t_2)$ |
| Deterministic space | $s_1(n)=o(s_2(n))$ | $\mathrm{SPACE}(s_1)\subsetneq\mathrm{SPACE}(s_2)$ |

**Simulation overhead:** logarithmic factor for time; constant factor for space with a fixed machine

**Meaning of strict containment:** some language is decidable with the larger budget but not the smaller one. Example: $n\log n=o(n^2)$, so the deterministic theorem applies to linear versus quadratic time.

## Diagonalization: linear time is weaker than quadratic time

**Diagonal machine $D$:** input $x$, length $n=|x|$

1. Decode $x$ as $M_x$; malformed description → reject
2. Universal simulation of $M_x(x)$: budget $\lceil n^{3/2}\rceil$ **simulator steps**
3. Simulated acceptance → reject; rejection/timeout → accept

**Upper bound:** clocked runtime $O(n^{3/2}\log n)\subseteq O(n^2)$

**Lower bound:** hypothetical linear-time decider $Q$ for the same language

- Fixed-$Q$ simulation: $O_Q(n\log n)$
- Sufficiently long padded description $x$ of $Q$ → simulation completed before deadline
- Opposite answers on $x$:

$$
D(x)=1-Q(x),
$$

**Contradiction:** $D$ and $Q$ supposedly deciding the same language

Here $x$ plays two roles: the description of $Q$ and the input given to $Q$. This forces disagreement with any proposed linear-time decider on one of its own descriptions.

$$
\boxed{\mathrm{DTIME}(n)\subsetneq\mathrm{DTIME}(n^2).}
$$

**Technical points:** clock → termination; padding → overcome constants/small-input exceptions

Here padding means adding ignored bits to a machine description. The encoded machine stays the same, but the longer input gives $D$ enough time to finish simulating the fixed linear-time decider $Q$.

### Consequences and limitations

- **P $\subsetneq$ EXP:** all polynomial bounds below $2^n$ eventually; hierarchy separation between $2^n$ and $2^{n^2}$
- **Space:** $2^{O(s)}$ configurations; $O(s)$-bit step counter → cutoff before unavoidable repetition
- **Nondeterminism:** swapped outcomes → “some branch rejects”; complement requires “all branches reject” → separate proof needed

For example, a nondeterministic machine with one accepting and one rejecting branch accepts. Swapping the two outcomes still leaves an accepting branch, so this does not complement the answer.

### Connection to undecidability

**Hypothetical halting decider $H$:**

- Prediction “$M(M)$ halts” → $R(M)$ loops
- Prediction “$M(M)$ loops” → $R(M)$ halts
- Self-input $R(R)$ → contradiction
- Hierarchy version: clock added → bounded simulation

## Ladner's theorem

**NP-intermediate:** in NP; outside P; not NP-complete under polynomial-time many-one reductions

$$
\boxed{\mathrm P\neq\mathrm{NP}
\implies\text{NP-intermediate languages exist}.}
$$

### Proof idea: pad SAT at a carefully controlled rate

**Padded language:**

$$
\mathrm{SAT}_H
=\{\varphi\,0\,1^{n^{H(n)}}:
\varphi\in\mathrm{SAT},\ n=|\varphi|\}.
$$

- Unambiguous formula/padding encoding
- Padded length: $N=n+1+n^{H(n)}$
- Polynomial in $N$: potentially much larger than polynomial in $n$

**Padding intuition:** extra bits leave the SAT question unchanged but enlarge the input size used to measure runtime. Fixed polynomial padding preserves NP-completeness; Ladner varies the padding to avoid both P and NP-completeness.

**Specially constructed $H$:** slowly growing, integer-valued, computable in $n^{O(1)}$ time; key properties:

$$
\begin{aligned}
\mathrm{SAT}_H\in\mathrm P&\iff H(n)=O(1),\\
\mathrm{SAT}_H\notin\mathrm P&\implies H(n)\to\infty.
\end{aligned}
$$

**Construction sketch, stage $n$:**

1. First roughly $\log\log n$ polynomially clocked machines
2. Correctness tests on all inputs of length $\leq\log n$
3. $H(n)$ = smallest passing index; increasing cap if none
4. Short test inputs → earlier $H$ values only → well-defined recursion

Testing correctness here is finite: check each short input's padding recursively, then brute-force its SAT core. The length cutoff keeps this work polynomial in the stage parameter $n$.

**Key reasoning:**

- Correct polynomial-time decider → eventual permanent success → bounded $H$
- Incorrect machine → some fixed counterexample → eventually fails every later test
- Bounded indices infinitely often → one index passes arbitrarily late → correct decider → membership in P

The tests eventually reach any fixed counterexample because their input-length cutoff grows. Thus, if no polynomial-time decider is correct, every fixed index is eventually eliminated and $H(n)$ must tend to infinity.

### The three conclusions

**Assumption:** $\mathrm P\neq\mathrm{NP}$

1. **In NP:** padding check + guessed satisfying assignment for core; polynomial in $N$
2. **Outside P:** membership in P → bounded $H$ → polynomial padding → SAT in P → contradiction
3. **Not NP-complete:** hypothetical SAT reduction $f$; output length $\leq n^d$. For sufficiently large core length $m$, $H(m)>2d$:

$$
m^{2d}<m^{H(m)}\leq|f(\varphi)|\leq n^d,
\qquad m<\sqrt n.
$$

**Shrinking algorithm:**

- Invalid output padding → unsatisfiable input
- Valid output → smaller core with equivalent satisfiability
- Repeat reduction + padding removal; brute-force below fixed threshold
- $O(\log\log n)$ steps → polynomial-time SAT → contradiction

Each successful round replaces the formula by one of length at most its square root, preserving the answer. Each round costs polynomial time in its current input length; after $O(\log\log n)$ rounds, the remaining formula has constant size and can be brute-forced.

**Required:** specially constructed $H(n)\to\infty$; arbitrary padding insufficient; no need for $H(n)=\omega(n)$
