## Diagonalization Limitation

Q: Can this technique be used to show that $P \neq NP$?

A: What do you mean?

Diagonalization features:

1. Treat Turing Machine as blackbox
2. There is an efficient representation of Turing Machine as bit strings
3. One TM is able to simulate any other TM without much overhead in time or space.

### Oracle Turing Machine

$M^O$ is like a normal TM but has a black box access to a language $O \subseteq \{0,1\}^*$. M has an additional oracle tape and a special state $q_{query}$. When M enters $q_{query}$, the content of the oracle tape $q$ is read. If $q\in O$, then M enters $q_{yes}$, else M enters $q_{no}$.

- Any TM model can be defined with respect to an oracle.
- Any complexity class can be defined w.r.t. an oracle. Notation $P^O, NP^O, \dots$

    For example: Any language $L$ can be used as an oracle. Let $O=L$. Then $P^L$ is the class of languages that can be decided by a polynomial time TM with access to oracle $L$.

    $TAUTOLOGY \in P^{SAT}$ and $\in NP^{SAT}$

- For any $O \in P$, $P^O = P$.

Theorem: There is an oracle $O$ relative to which $P=NP$. $\exist O \in \{0,1\}^*$ s.t. $p^O = NP^O$

Proof: Let $O = \{<M,x,1^n>: \text{M accepts x within 2^n steps}$

$O \in E = DTIME(2^{O(n)})$
$O \in E \subseteq EXP = DTIME(2^n^{O(1)})$
$EXP \subseteq P^O$ (just call $O$ with the given input)

Also $NP^O \subseteq EXP$ (brute force NP choices + simulate $O$ calls)

$EXP \subseteq P^O \subseteq NP^O \subseteq EXP \therefore p^O = NP^O = EXP$

Theorem: There is an oracle $O$ relative to which $P\neq NP$. $\exist O \in \{0,1\}^*$ s.t. $p^O \neq NP^O$

Proof: Language: $L = \{1^n: \exist \text{ a string of Length n in O}\}$

Claim: $L \in NP^O$

Build $O$ in stages s.t. $L \notin P^O$. We start with empty O. Keep adding strings.

State 1: pick n large enough so that the fate of no string of length n belonging to O has yet been decided. 

Let $M_i$ be the i-th TM. Run $M_i$ for << $2^n$ steps. 

- Whenever $M_i$ queries a string x that's not decided we declare that $x \notin O$. 
- Whenever $M_i$ queries a string x that's already decided we respond consistently. 
- When $M_i$ halts, we ensure that it decide wrongly.
    - If $M_i$ accepts, declare all remaining strings of length n to not belong to $O$
    - If $M_i$ rejects, add some unqueried x of length n to $O$

Therefore $L \notin P^O$ (in fact $L \notin DTIME(o(2^n))$)


Fact: For a random oracle O, $P^O \neq NP^O$ with probability 1.
