# Lecture 7: The Polynomial Hierarchy

**Main point:** NP/coNP + fixed number of alternating existential/universal blocks

## Definitions and quantifier order

**Bounds:** polynomial-length quantified strings; polynomial-time predicate $R$

Here $R$ is a yes/no check, with output 1 for success. The quantifiers describe the membership condition; they do not give a polynomial-time algorithm for trying every quantified string.

| Class | Membership condition |
| --- | --- |
| $\mathrm{NP}=\Sigma_1^{\mathrm P}$ | $\exists u\;R(x,u)=1$ |
| $\mathrm{coNP}=\Pi_1^{\mathrm P}$ | $\forall u\;R(x,u)=1$ |
| $\Sigma_2^{\mathrm P}$ | $\exists u\forall v\;R(x,u,v)=1$ |
| $\Pi_2^{\mathrm P}$ | $\forall u\exists v\;R(x,u,v)=1$ |

- $\exists u\forall v$: one fixed $u$ for all $v$
- $\forall v\exists u$: $u$ allowed to depend on $v$

**Bit example:** $\forall v\exists u\;(u=v)$ true; $\exists u\forall v\;(u=v)$ false

For the first order, choose $u=v$ after seeing $v$. For the second, either fixed choice of $u$ fails when $v$ is the other bit.

**General $\Sigma_i^{\mathrm P}$ form**, fixed $i\geq1$:

$$
x\in L\iff\exists u_1\forall u_2\exists u_3\cdots Q_i u_i\;
R(x,u_1,\ldots,u_i)=1.
$$

- $\Pi_i^{\mathrm P}$: same alternation, starting with $\forall$
- Index $i$: number of **blocks**, independent of input length

$$
\Sigma_0^{\mathrm P}=\Pi_0^{\mathrm P}=\mathrm P,
\qquad\Pi_i^{\mathrm P}=\operatorname{co}\Sigma_i^{\mathrm P}.
$$

**Complement:** flip all quantifiers + negate predicate

For example, negating $\exists u\forall v\;R(x,u,v)=1$ gives $\forall u\exists v\;R(x,u,v)=0$. This explains why complementing a $\Sigma_i^{\mathrm P}$ language gives a $\Pi_i^{\mathrm P}$ language with the same number of blocks.

## Example: exact maximum independent-set size

**$\alpha(G)=k$:** size-$k$ independent set + no larger independent set

**Predicate:** $I(G,S)$ = “$S$ independent”

$$
\begin{aligned}
\alpha(G)=k\iff\exists S\forall T\;[
&I(G,S)\land |S|=k\\
&\land(|T|\neq k+1\lor\neg I(G,T))].
\end{aligned}
$$

- Set encoding: vertex-incidence bit vector
- No size-$(k+1)$ independent set → no larger one; independent subsets remain independent

The universal $T$ ranges over every vertex subset. The size guard $|T|\neq k+1$ skips irrelevant sizes; only size-$(k+1)$ sets must fail the independence test.

- Membership: $\mathrm{EXACT\text{-}INDSET}\in\Sigma_2^{\mathrm P}$
- Independent $S$/$T$ conditions → also $\forall T\exists S$ → membership in $\Pi_2^{\mathrm P}$
- No implied separation from NP or coNP

Swapping the quantifiers works here because the condition on $S$ never refers to $T$: one size-$k$ independent set works for every $T$. Quantifiers cannot generally be swapped when the conditions depend on both variables.

## Example: an equivalent small CNF

**MIN-CNF input:** CNF $\varphi$, bound $k$

**Witness:** equivalent CNF $\psi$; same variables; encoding length at most $k$

$$
\exists\psi\forall a\;
[\psi\text{ is valid},\ |\psi|\leq k,\ \psi(a)=\varphi(a)].
$$

**Guess formula + check all assignments** → MIN-CNF in $\Sigma_2^{\mathrm P}$

**Equivalent** means the same truth value on every assignment. Two formulas can both be satisfiable without being equivalent—for example, $a$ and $\neg a$.

- $k\geq|\varphi|$: trivial witness $\psi=\varphi$
- Otherwise: polynomial witness length, even for binary $k$

**Complement:** every candidate has a counterexample

$$
\forall\psi\exists a\;
[\psi\text{ is invalid or too large}\ \lor\ \psi(a)\neq\varphi(a)],
$$

- Complement in $\Pi_2^{\mathrm P}$
- Polynomial-size candidate encodings
- Malformed candidates: automatic pass in complementary test

For each valid candidate $\psi$, the counterexample assignment $a$ may be different. This dependence is exactly what the order $\forall\psi\exists a$ permits.

## The hierarchy and its containments

$$
\boxed{\mathrm{PH}=\bigcup_{i\geq0}\Sigma_i^{\mathrm P}
=\bigcup_{i\geq0}\Pi_i^{\mathrm P}.}
$$

Each language in PH belongs to some fixed level. Different languages may need different levels; the number of blocks for one language cannot grow with its input length.

**Unused quantifier blocks** → containments:

$$
\boxed{\Sigma_i^{\mathrm P}\cup\Pi_i^{\mathrm P}
\subseteq\Sigma_{i+1}^{\mathrm P}\cap\Pi_{i+1}^{\mathrm P}.}
$$

**Same-level containment:** not implied between $\Sigma_i^{\mathrm P}$ and $\Pi_i^{\mathrm P}$

An unused variable cannot affect the answer. For example, $\exists u\;R(x,u)=1$ is equivalent to $\forall v\exists u\;R(x,u)=1$ because $R$ ignores $v$; this places NP inside $\Pi_2^{\mathrm P}$.

## Collapse theorems

A **collapse** means all higher levels equal a fixed lower level. Extra quantifier alternations then add no expressive power.

**P = NP → PH = P**, induction on blocks:

1. Base: NP = coNP = P
2. Fix first existential witness → remaining $\Pi_{i-1}^{\mathrm P}$ predicate in P by induction
3. Guess witness + check remainder → NP = P
4. Complement → same result for $\Pi$ classes

**Equality at level $i\geq1$ → collapse:**

$$
\boxed{\Sigma_i^{\mathrm P}=\Pi_i^{\mathrm P}
\implies\mathrm{PH}=\Sigma_i^{\mathrm P}.}
$$

**Proof idea:** a $\Sigma_{i+1}^{\mathrm P}$ condition has an outer existential block followed by a $\Pi_i^{\mathrm P}$ condition. Under the assumed equality, rewrite the inner condition in $\Sigma_i^{\mathrm P}$ form. Its leading existential block merges with the outer one, leaving only $i$ blocks; repeat for higher levels.

**Consequence:** NP = coNP → PH = NP; implication P = NP still unknown

## Complete problems

**$\Sigma_i^{\mathrm P}$-complete:** membership + polynomial-time reductions from every language in $\Sigma_i^{\mathrm P}$

**Complete problem:** quantified Boolean circuit satisfiability; $i$ alternating blocks

A Boolean circuit is an acyclic network of AND, OR, and NOT gates. Once its input bits are fixed, evaluating gates in order takes polynomial time; the difficulty comes from the quantified choices of inputs.

$$
\exists u_1\forall u_2\cdots Q_i u_i\;C(u_1,\ldots,u_i)=1.
$$

- **Membership:** polynomial-time circuit evaluation
- **Hardness:** fixed $x$ → predicate circuit of polynomial size; same quantifier prefix

- Universal starting block → $\Pi_i^{\mathrm P}$-complete version
- CNF conversion: correct placement of auxiliary existential variables required

**PH-complete problem → collapse:** such a problem must itself belong to some fixed level $\Sigma_k^{\mathrm P}$. Reducing every PH language to it places all of PH at that same level, since a polynomial-time reduction adds no quantifier blocks.
