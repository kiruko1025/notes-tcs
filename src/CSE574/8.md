# Lecture 8: Oracle Characterizations of PH and Space Complexity

**Main points:** NP oracle level ↔ quantifier block; space-bounded acceptance ↔ configuration reachability

## PH through oracles

**Class oracle notation:**

$$
\mathrm{NP}^{\mathcal C}=\bigcup_{A\in\mathcal C}\mathrm{NP}^A.
$$

- One fixed oracle language per machine
- Complete $K$ for $\mathcal C$ → query reductions to $K$ → $\mathrm{NP}^{\mathcal C}=\mathrm{NP}^K$

The union permits different machines to use different oracle languages. With a complete language $K$, each query to any chosen $A\in\mathcal C$ can instead be translated into a query to $K$, preserving its answer.

**Oracle characterization:** $i\geq1$; $A$ complete for $\Sigma_{i-1}^{\mathrm P}$

$$
\boxed{\Sigma_i^{\mathrm P}=\mathrm{NP}^A,
\qquad\Pi_i^{\mathrm P}=\mathrm{coNP}^A.}
$$

**coNP$^A$:** complement of accepted language; same oracle $A$

**Second level:**

$$
\boxed{\mathrm{NP}^{\mathrm{NP}}=\mathrm{NP}^{\mathrm{SAT}}=\Sigma_2^{\mathrm P}.}
$$

## Proof of the second-level equality

### Quantifiers → SAT oracle

**Given:** $x\in L\iff\exists u\forall v\;R(x,u,v)=1$

1. Guess polynomial-length $u$
2. Counterexample query: $\exists v\;R(x,u,v)=0$ → SAT via Cook–Levin
3. Oracle **no** → accept

**Correctness:** accepting branch ⇔ some $u$ valid for every $v$

The SAT oracle searches for a counterexample to the guessed $u$. Its no answer certifies that no counterexample exists, exactly the universal condition we need.

### SAT oracle → quantifiers

**Polynomial-time nondeterministic machine; existential guesses:**

- $c$: branch choices
- $a_j$: proposed oracle answers
- $u_j$: satisfying assignments for claimed yes answers

**Replay:**

- Replay using $c,a$ → actual queries $\varphi_j$
- Earlier answers determine later queries: **adaptivity preserved**
- Total guessed data: polynomial length

Once the branch choices and proposed answers are fixed, replay is deterministic. This lets the predicate reconstruct even queries that depend on earlier answers, then verify the entire proposed computation.

**Polynomial-time predicate $R$:** accepting replay + checks for every used query

$$
\begin{aligned}
a_j=1&\Rightarrow\varphi_j(u_j)=1,\\
a_j=0&\Rightarrow\varphi_j(v_j)=0.
\end{aligned}
$$

**Quantified form:**

$$
\boxed{x\in L\iff
\exists(c,a,\mathbf u)\forall\mathbf v\;
R(x,c,a,\mathbf u,\mathbf v)=1.}
$$

- **Yes answers:** guessed satisfying witnesses
- **No answers:** universal tuple excluding all satisfying assignments
- **Correctness:** passing guesses ↔ genuine accepting computation with correct oracle answers
- Bookkeeping: polynomial clock; padded unused entries; malformed queries → no
- **Essential:** universal verification of no answers; guessing alone insufficient

**Why one universal tuple suffices:** if any claimed no query is actually satisfiable, choose its satisfying assignment as that tuple's component. That tuple makes the check fail, exposing the incorrect transcript.

**Higher levels:** yes checks in $\Sigma_{i-1}^{\mathrm P}$; no checks in $\Pi_{i-1}^{\mathrm P}$; combined prefix ≤ $i$ alternating blocks

## What counts as space?

| Tape | Counts toward space? |
| --- | --- |
| Read-only input | No |
| Read/write work tapes | **Yes:** maximum cells used |
| Write-only output | No; no rereading as memory |

- $\mathrm{SPACE}(s(n))$: deterministic decision using $O(s(n))$ work space
- $\mathrm{NSPACE}(s(n))$: nondeterministic version; bound on **every branch**
- Assumptions: $s(n)\geq\log n$; space-constructible $s$

Excluding the input tape makes sublinear space meaningful: the machine can reread a large input while storing only a few indices or counters. Storing one input position requires $O(\log n)$ bits.

**Cell reuse:** no extra space. **Time bound:** $t$ steps → at most $O(t)$ visited cells

$$
\mathrm{DTIME}(t(n))\subseteq\mathrm{SPACE}(t(n)).
$$

**Counter example:** $s$ bits → $2^s$ steps; small space ≠ small time

## Configuration graphs

**Fixed machine $M$, input $x$:**

- Configuration = state + work-tape contents + all head positions
- Fixed input: no copy needed inside each configuration

A configuration records everything needed to determine the next possible steps. The past history is irrelevant once this snapshot and the fixed input are known.

**Graph $G_{M,x}$:**

- Vertices: configurations
- Directed edges: legal one-step transitions
- Successors: at most one if deterministic; possibly several if nondeterministic

| Stored information | Bits |
| --- | --- |
| Work-tape contents | $O(s(n))$ |
| State | $O(1)$ |
| Work-head positions | $O(\log s(n))$ |
| Input-head position | $O(\log n)$ |

**Using $s(n)\geq\log n$:**

$$
\boxed{\text{configuration size}=O(s(n)),
\qquad K=|V(G_{M,x})|\leq2^{O(s(n))}.}
$$

An $O(s(n))$-bit description has at most $2^{O(s(n))}$ possible values. Thus logarithmic space gives a polynomial-size configuration graph; linear space can give an exponential-size graph.

**Edge check:** direct comparison with transition rules; no full graph needed

**CNF encoding**, auxiliary variables $z$:

$$
C\to C'\iff\exists z\;\Phi_{M,x}(C,C',z)=1.
$$

The auxiliary bits $z$ encode the internal computation of the transition check, as in Cook–Levin. A satisfying assignment certifies a **single legal step**, not a whole accepting computation.

## Acceptance is reachability

**Unique accepting configuration:** erase work tapes + reset heads; same asymptotic space

$$
\boxed{M\text{ accepts }x\iff C_{\mathrm{start}}\leadsto C_{\mathrm{accept}}.}
$$

Each computation branch traces a path through the graph. Reaching an accepting configuration therefore means that at least one branch accepts; unreachable acceptance means every branch fails.

- Repeated deterministic configuration → loop → impossible for a decider
- Cycle removal → simple accepting path with at most $K-1$ edges

If a path visits the same configuration twice, remove the segment between those visits. The remaining path is still valid, so an accepting path never needs to repeat a vertex.

**Deterministic simulation:** enumerate configurations → check all pairs for edges → graph search

$$
K^2\operatorname{poly}(n+s(n))=2^{O(s(n))}.
$$

Because $s(n)\geq\log n$, even a polynomial factor in $n$ fits within $2^{O(s(n))}$. Squaring the configuration count only changes the constant in the exponent.

**Result:**

$$
\boxed{\mathrm{SPACE}(s(n))\subseteq\mathrm{NSPACE}(s(n))
\subseteq\mathrm{DTIME}\!\left(2^{O(s(n))}\right).}
$$

**Time bound only:** explicit graph storage potentially exponential

**Next:** Savitch—implicit reachability search for smaller space

## Stronger time-to-space bound

**Williams, without proof:** deterministic multitape machines; $t(n)\geq n$

$$
\mathrm{DTIME}(t(n))
\subseteq\mathrm{SPACE}\!\left(\sqrt{t(n)\log t(n)}\right).
$$

**Keep the logarithmic factor** inside the square root
