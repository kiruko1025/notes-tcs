# Lecture 6: Oracles and the Limits of Relativization

**Main point:** equality for some oracles, separation for others → barrier to fully relativizing proofs

## Oracle machines

- **Oracle:** language $O\subseteq\{0,1\}^*$
- **Machine $M^O$:** write query $q$ → exact membership answer in one oracle step

**Query-writing cost:** polynomial time → polynomially many queries, each polynomial-length

| Class | Machine with oracle $O$ |
| --- | --- |
| $\mathrm P^O$ | Deterministic polynomial time |
| $\mathrm{NP}^O$ | Nondeterministic polynomial time; some accepting branch |

**Oracle answers:** fixed by $O$, never nondeterministic choices

An oracle is an extra ability granted to the model, not necessarily an efficient algorithm we know how to implement. The querying machine pays to write the question, but not to compute the oracle's answer.

Basic facts:

$$
O\in\mathrm P^O,\qquad
\mathrm P\subseteq\mathrm P^O\subseteq\mathrm{NP}^O.
$$

- $O\in\mathrm P$ → direct query simulation → $\mathrm P^O=\mathrm P$, $\mathrm{NP}^O=\mathrm{NP}$
- $\mathrm{TAUTOLOGY}\in\mathrm P^{\mathrm{SAT}}$: falsifying-assignment query → reverse answer; polynomial SAT encoding to avoid CNF blowup

## An oracle making P equal NP

Let

$$
A=\{\langle M,x,1^m\rangle:
M\text{ deterministically accepts }x\text{ within }2^m\text{ steps}\}.
$$

**Containment chain:**

$$
\boxed{\mathrm{EXP}\subseteq\mathrm P^A
\subseteq\mathrm{NP}^A\subseteq\mathrm{EXP}.}
$$

**1. $A\in\mathrm E$:** query length $N$; $m\leq N$; direct simulation in $2^{O(N)}$

**2. EXP $\subseteq\mathrm P^A$:** decider $M$, runtime $2^{p(n)}$ → one query

$$
\langle M,x,1^{p(|x|)}\rangle.
$$

Polynomial query length; answer = membership in $L$

The query writes the exponent $p(|x|)$ in unary, not the full $2^{p(|x|)}$-step computation. The oracle performs the expensive decision in one charged step.

**3. $\mathrm{NP}^A\subseteq$ EXP:**

- Branch time $p(n)$ → at most $2^{O(p(n))}$ branches
- Per branch: polynomially many polynomial-length queries
- Oracle simulation per query: $2^{O(p(n))}$
- Exhaustive branch simulation: total $2^{n^{O(1)}}$

We multiply the number of branches by the cost of simulating each branch. Both have polynomial exponents, and multiplying powers of two adds those exponents, so the total remains in EXP.

**Result:** $\mathrm P^A=\mathrm{NP}^A=\mathrm{EXP}$

## An oracle making P differ from NP

**Target language:**

$$
L_B=\{1^n:\exists y\in\{0,1\}^n,\ y\in B\}
$$

**Goal:** in $\mathrm{NP}^B$, outside $\mathrm P^B$

**NP membership:** guess length-$n$ string $y$ → query $B$ → accept on yes

The input $1^n$ has length $n$, so guessing $n$ bits is polynomial-time. Yet there are $2^n$ possible witnesses; a deterministic machine cannot query them all within a polynomial clock.

**Enumeration:** deterministic oracle machines + polynomial clocks $(M_i,p_i)$; every polynomial-time decider covered by some sufficient clock

At stage $i$:

1. Fresh length $n$: all membership undecided; $p_i(n)<2^n$
2. Clocked run of $M_i^B(1^n)$: fixed answers respected; new queries answered **no**, permanently
3. Final answer → opposite oracle membership:

| Machine answers | Set membership at length $n$ | True answer for $L_B$ |
| --- | --- | --- |
| Accept | All strings outside $B$ | No |
| Reject or time out | One **unqueried** string in $B$; all others outside | Yes |

- $2^n$ candidates, fewer than $2^n$ queries → unqueried string available
- Entire length-$n$ slice frozen before next stage
- After all stages: remaining undecided strings outside $B$

**Consistency:** no changed query answers → permanent error for each decider

Each earlier stage fixes only finitely many strings, leaving a fresh length available. Adding an unqueried string cannot change the simulated run: the machine never saw that string's answer.

These stages define a single fixed language $B$. The oracle does not change during a real computation; preserving every answer used in a stage ensures that its simulated error persists for the final oracle.

$$
\boxed{L_B\in\mathrm{NP}^B\setminus\mathrm P^B.}
$$

## The relativization barrier

**Relativizing proof:** valid with any common oracle added to all machines

**Baker–Gill–Solovay:**

$$
\exists A:\mathrm P^A=\mathrm{NP}^A,
\qquad
\exists B:\mathrm P^B\neq\mathrm{NP}^B.
$$

- Relativizing equality proof: contradicted by $B$
- Relativizing inequality proof: contradicted by $A$
- P versus NP resolution: **nonrelativizing ingredient required**
- Limitation on fully relativizing arguments, not all diagonalization

The two oracles give machines different extra abilities, so the opposite results are consistent. They show that a proof working unchanged for every oracle cannot settle ordinary P versus NP.

**Bennett–Gill, without proof:** independent inclusion of each string with probability $1/2$ → $\mathrm P^O\neq\mathrm{NP}^O$ almost surely; ordinary P versus NP still unresolved
