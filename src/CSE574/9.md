# Lecture 9: Space Complexity and Savitch's Theorem

**Key idea: space can be reused.** Exhaustive search and sequential recursive calls may take enormous time while using little memory.

## Space complexity and configuration graphs

Only **read/write work tapes** count toward space usage. The input is read-only; the output is write-only.

- $\mathrm{SPACE}(s(n))$: languages decidable deterministically using $O(s(n))$ space.
- $\mathrm{NSPACE}(s(n))$: nondeterministic version; the space bound holds on every branch.
- Assume $s(n)\geq\log n$ and $s$ is **space-constructible** (computable using $O(s(n))$ space).

For machine $M$ and input $x$, the **configuration graph** $G_{M,x}$ has:

- Vertices: work-tape contents, head positions, and machine state.
- Edges $C\to C'$: legal one-step transitions, checkable on demand.
- $O(s(n))$ bits per configuration, hence at most $N=2^{O(s(n))}$ vertices.

After arranging a unique accepting configuration,

$$
M\text{ accepts }x
\iff C_{\mathrm{start}}\text{ reaches }C_{\mathrm{accept}}.
$$

A deterministic machine that repeats a configuration loops forever. For nondeterministic machines, an accepting path can be shortened to a simple path of fewer than $N$ edges.

Thus

$$
\mathrm{DTIME}(s(n))
\subseteq\mathrm{SPACE}(s(n))
\subseteq\mathrm{NSPACE}(s(n))
\subseteq\mathrm{DTIME}\!\left(2^{O(s(n))}\right).
$$

The last inclusion follows by explicitly constructing the configuration graph and searching it. This gives a time bound, not a small-space simulation.

## Classes and examples

$$
\begin{aligned}
\mathrm{PSPACE}&=\bigcup_{c>0}\mathrm{SPACE}(n^c),&
\mathrm{NPSPACE}&=\bigcup_{c>0}\mathrm{NSPACE}(n^c),\\
\mathrm{L}&=\mathrm{SPACE}(\log n),&
\mathrm{NL}&=\mathrm{NSPACE}(\log n).
\end{aligned}
$$

Logspace can store constantly many counters up to $n^{O(1)}$ and repeatedly scan the input.

- **$\mathrm{3SAT}\in\mathrm{PSPACE}$:** enumerate assignments, storing and testing one at a time. Since 3SAT is NP-complete, $\mathrm{NP}\subseteq\mathrm{PSPACE}$.
- **$\mathrm{EVEN}\in\mathrm{L}$:** keep one parity bit and XOR each input bit into it. In fact, constant space suffices.
- **$\mathrm{MULT}=\{\langle a,b,c\rangle:c=ab\}\in\mathrm{L}$:** use grade-school multiplication one output column at a time. Store digit indices, a column sum, and a carry; rescan input bits as needed. If the total input has $\ell$ bits, each stored quantity needs $O(\log\ell)$ bits. The bound is logarithmic in the **encoding length**, not the integers' values.

## Directed reachability

$$
\mathrm{PATH}=\{\langle G,s,t\rangle:G\text{ has a directed path from }s\text{ to }t\}.
$$

**Claim: $\mathrm{PATH}\in\mathrm{NL}$.** For a graph with $v$ vertices:

1. Start at $s$; accept if already at $t$.
2. Nondeterministically guess the next vertex and verify the edge.
3. Accept upon reaching $t$; reject the branch after $v-1$ edges without success.

Only the current/next vertices and a counter are stored: $O(\log v)$ bits. If a path exists, a simple path of at most $v-1$ edges exists.

Equivalently, verify a proposed path using a **read-once certificate tape**; the graph input can be reread freely.

- Directed PATH in L is open; it is equivalent to $\mathrm{L}=\mathrm{NL}$ via NL-completeness (covered later).
- **Undirected** reachability, $\mathrm{USTCON}$, is in L by Reingold's theorem.
- Ordinary BFS/DFS store too much information to establish a logspace bound.

## Savitch's theorem

For space-constructible $s(n)\geq\log n$,

$$
\boxed{\mathrm{NSPACE}(s(n))\subseteq\mathrm{SPACE}(s(n)^2).}
$$

### Proof: recursive midpoint search

Use the configuration graph with at most $N=2^{O(s(n))}$ vertices. Define

$$
\mathrm{Reach}(u,v,i)=1
\iff \text{a path of length at most }2^i\text{ connects }u\text{ to }v.
$$

**Base case:** $\mathrm{Reach}(u,v,0)$ holds if $u=v$ or $(u,v)$ is an edge.

**Recurrence:** every path of length at most $2^i$ can be split at a midpoint $z$:

$$
\mathrm{Reach}(u,v,i)
=\bigvee_z\left(
\mathrm{Reach}(u,z,i-1)\land
\mathrm{Reach}(z,v,i-1)
\right).
$$

Enumerate all $z$ deterministically and evaluate the two recursive calls sequentially. Generate configurations and check edges **implicitly**, without storing the entire graph.

The main call is

$$
\mathrm{Reach}(C_{\mathrm{start}},C_{\mathrm{accept}},\lceil\log_2 N\rceil).
$$

**Space analysis:**

- Each level stores $u,v,z,i$ and control information: $O(\log N)$ bits.
- Recursion depth: $O(\log N)$.
- Sibling calls reuse workspace, so
  $S(N,i)\leq S(N,i-1)+O(\log N)$, with no factor of two.

Therefore,

$$
S(N,\lceil\log_2 N\rceil)
=O(\log^2 N)=O(s(n)^2).
$$

The time can be large; the saving comes from storing only one active recursion stack.

### Consequences

$$
\mathrm{NL}\subseteq\mathrm{SPACE}(\log^2 n),
\qquad
\boxed{\mathrm{PSPACE}=\mathrm{NPSPACE}.}
$$

Squaring a polynomial preserves polynomial space. Squaring $\log n$ does not preserve logarithmic space, so Savitch does not settle L versus NL.

## PSPACE completeness

A language $B$ is:

- **PSPACE-hard** if every $A\in\mathrm{PSPACE}$ satisfies $A\leq_p B$.
- **PSPACE-complete** if it is PSPACE-hard and belongs to PSPACE.

Here $\leq_p$ means polynomial-time many-one reduction. If any PSPACE-complete problem is in P, then $\mathrm{P}=\mathrm{PSPACE}$, implying $\mathrm{P}=\mathrm{NP}$. Whether $\mathrm{P}=\mathrm{PSPACE}$ is open.

### Bounded-space machine acceptance

$$
\mathrm{SPACE\text{-}TMSAT}
=\{\langle M,x,1^b\rangle:
M\text{ is deterministic and accepts }x
\text{ within }b\text{ work-tape cells}\}.
$$

This problem is PSPACE-complete:

- **Membership:** simulate $M$, rejecting if it exceeds $b$ cells or the bounded configuration-count time limit. The current configuration and step counter require polynomial space in the total input length.
- **Hardness:** if $A$ has a decider $M_A$ using space $p(|x|)$, reduce
  $x\mapsto\langle M_A,x,1^{p(|x|)}\rangle$.

The bound is **unary**, ensuring the allowed workspace is polynomial in the encoded instance size.

## Quantified Boolean formulas

A fully quantified Boolean formula is

$$
\Psi=Q_1x_1\cdots Q_kx_k\,\varphi(x_1,\ldots,x_k),
\qquad Q_i\in\{\exists,\forall\},\quad x_i\in\{0,1\}.
$$

All variables are bound, so $\Psi$ is either true or false. Unlike a fixed PH level, the number of quantifier alternations may grow with the input.

**Example:**

$$
\forall x\,\exists y\,
((x\land y)\lor(\neg x\land\neg y))
\iff \forall x\,\exists y\,(x=y)
$$

is true: choose $y=x$. Reversing the order to $\exists y\,\forall x\,(x=y)$ makes it false.

- SAT corresponds to $\exists x_1\cdots\exists x_k\,\varphi$.
- TAUTOLOGY corresponds to $\forall x_1\cdots\forall x_k\,\varphi$.

$$
\mathrm{TQBF}=\{\Psi:\Psi\text{ is a true fully quantified Boolean formula}\}.
$$

**Theorem:** TQBF is PSPACE-complete. **Proof deferred to the next lecture.**

## Main relationships

$$
\mathrm{L}\subseteq\mathrm{NL}\subseteq\mathrm{P}
\subseteq\mathrm{NP}\subseteq\mathrm{PH}
\subseteq\mathrm{PSPACE}=\mathrm{NPSPACE}
\subseteq\mathrm{EXP}.
$$

The inclusions are not all known to be strict. In particular, $\mathrm{NL}\subseteq\mathrm{P}$ follows because logspace configuration graphs have polynomially many vertices.
