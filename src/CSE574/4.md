## Time Hierarchy Theorem 2

### proof

define: $t_{1.5} (n)=n^{1.5}$

Diagonalize on x is input x on y is machine m, diagonal is M(M)

Consider function $f(x)$:

1. Interpret x as a Turing Machine $M_x$
2. Rum $M_x$ on input $x$ for $t_{1.5}(|x|)$ steps
3. If $M_x$ accepts, reject, else accept

Claim: $f(x)$ can be computed in time $t_2 (|x|)$

Claim: $f(x)$ can't be computed in time $t_1(|x|)$

Let $Q$ be a Turing Machine running in time $t_1(|x|)$. Consider any description x of Q.

Run $Q(x)$:

Claim: $Q(x)\neq f(x)$

Because $f(x)$ is defined as the opposite of what $Q$ does

Some technicalities:

1. W.l.o.g. we focus on machine with 2 tapes (any TM can be simulated by one having 2 tapes for T steps in time $O(T^2)$) ($O(T\log T)$ is possible)
2. Asymptotics only kick in for large enough length. Make sure that every TM can be encoded as a string of arbitrary large length (padding idea)
3. The functions $t_1(n)$ and $t_2(n)$ need to be "nice" which means time-constructible. ($t(n)$ is time-constructible if 1) $t(n) \leq n$, 2) there is a TM M that computes $X |-> t(|x|)$ in time $O(t(|x|))$

Note: if we remove time bounds, this shows that the following is undecidable: $f(M) = 0 if M(M) accepts, 1 else$. This function f can be reduced to halting problem. Therefore halting problem is undecidable.

## NP-intermediate Languages/Problems

### Ladner's Theorem

If $P\neq NP$, there are problems in $NP$ that are not in $P$ and not in $NP-complete$

Start with $SAT$, add padding (extra bits)

$$
SAT_H = \phi 01^n^{H(n)} : \phi \in SAT, n = |phi|
$$

$H(n)$ will be designed in such a way that $SAT_h \in P$ iff $H(n) = O(1)$

1. $SAT_H \in P -> H(n)=O(1)$ -> padding bits are polynomially many -> $SAT_H$ is NP-complete same as $SAT$ -> $P=NP$
2. $SAT_H$ is NP-complete -> $H(n) = \omega(n)$ (super constant) -> $SAT \leq_p SAT-H$ starting from a $SAT$ instance, inpoly time a $SAT_H$ is given that's heavily padded. remove padding get a smaller $SAT$ instance. recursively make $SAT$ instance smaller & smaller until solvable by brute force -> $P=NP$
