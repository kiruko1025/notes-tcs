# Lecture 4: SAT Reductions, coNP, and Exponential Time

**Main point:** hardness transfer

$$
\boxed{\mathrm{SAT}\leq_p\mathrm{3SAT}
\leq_p\mathrm{INDSET}\leq_p\mathrm{VC}.}
$$

**All targets in NP** → all NP-complete

## SAT → 3SAT

**Four-literal split:** fresh variable $z$

$$
\begin{aligned}
C&=\ell_1\lor\ell_2\lor\ell_3\lor\ell_4,\\
C'&=(\ell_1\lor\ell_2\lor z)
\land(\neg z\lor\ell_3\lor\ell_4).
\end{aligned}
$$

**Per original assignment:** $C=1\iff\exists z\;C'=1$

- First pair true → choose $z=0$
- Second pair true → choose $z=1$
- All four false → both $z$ and $\neg z$ required → contradiction

**Equisatisfiable:** satisfiability preserved through some choice of new variables; no equivalence for arbitrary fixed $z$

The new variable connects the two smaller clauses. A fresh variable for each split avoids accidentally tying unrelated clauses together.

**Longer clauses:** repeated two-literal splits

$$
\ell_1\lor\cdots\lor\ell_r
\quad\rightsquigarrow\quad
(\ell_1\lor\cdots\lor\ell_{r-2}\lor z)
\land(\neg z\lor\ell_{r-1}\lor\ell_r).
$$

- $r\geq4$ literals → $r-3$ fresh variables, $r-2$ width-three clauses
- Short clauses: unchanged; empty clause: fixed contradiction
- Total construction: polynomial time

**Result:** fixed $k\geq3$ → $k$-SAT NP-complete; 2SAT in P

## 3SAT → Independent Set

**Input:** formula with $m$ clauses

1. One vertex per **literal occurrence**
2. Within-clause edges: clique; triangle for three literals
3. Across-clause edges: complementary literals, e.g. $x$ and $\neg x$
4. Threshold $k=m$

Repeated literals still create separate vertices: each vertex represents a choice for one particular clause. Selecting $x$ in one clause and $\neg x$ in another would demand incompatible truth values, so an edge forbids that pair.

**Role of the edges:** clause cliques permit at most one selected occurrence per clause. Reaching size $m$ therefore forces a choice from every clause; conflict edges keep those choices consistent.

**Why it works:**

- **Assignment → set:** one true occurrence per clause → $m$ nonadjacent vertices
- **Set → assignment:** size $m$ → exactly one occurrence per clause; no conflicting literals → consistent satisfying assignment

- **Size:** at most $3m$ vertices, $O(m^2)$ edges
- Empty clause → fixed no instance; zero clauses → threshold zero
- **NP membership:** polynomial-time check of selected vertices

## Independent Set → Vertex Cover

**Vertex cover:** at least one endpoint of every edge

$$
\boxed{S\text{ independent}\iff V\setminus S\text{ is a vertex cover}.}
$$

**Reason:** no edge entirely inside $S$. With $v=|V|$:

$$
\langle G,k\rangle\mapsto\langle G,v-k\rangle.
$$

- Independent set size $\geq k$ ⇔ cover size $\leq v-k$
- $k>v$ → fixed no instance
- **Verification:** polynomial-time edge coverage check

**Example:** in the path $1-2-3$, independent set $\{1,3\}$ has complementary cover $\{2\}$. Every edge touches vertex 2.

**Maximum independent-set size** $\alpha(G)$; **minimum cover size** $\tau(G)$:

$$
\alpha(G)+\tau(G)=|V|.
$$

## coNP-complete problems

**coNP-complete:** in coNP + polynomial-time reductions from every coNP language

| Problem | Yes condition | Why complete |
| --- | --- | --- |
| UNSAT | No satisfying assignment for the CNF | SAT complement on valid inputs |
| TAUTOLOGY | Truth under every assignment | Unsatisfiable $\varphi$ ⇔ tautological $\neg\varphi$ |

**UNSAT hardness:** $A\in\mathrm{coNP}$ → reduce $\overline A$ to SAT → same map reduces $A$ to UNSAT

The reduction produces a satisfiable formula exactly when $x\notin A$. Thus it produces an unsatisfiable formula exactly when $x\in A$; the map itself needs no change.

**TAUTOLOGY:** general formulas. CNF case: polynomial-time check for a complementary pair in every clause

A CNF is true on every assignment only if each clause is always true. A clause containing both $z$ and $\neg z$ is always true; without such a pair, all its literals can be made false together.

$$
\mathrm P\subseteq\mathrm{NP}\cap\mathrm{coNP},\qquad
\mathrm{NP}\neq\mathrm{coNP}\implies\mathrm P\neq\mathrm{NP}.
$$

**Open:** P = NP $\cap$ coNP?

## Nullstellensatz: certificates of no solution

**Setting:** algebraically closed field, e.g. $\mathbb C$

**Common zero:** one assignment making every $f_i$ equal to zero. The certificate below is a polynomial identity, valid for every assignment—not just a tested sample.

**No common zero of $f_1,\ldots,f_m$** ⇔ existence of polynomials $g_i$ satisfying

$$
\boxed{\sum_{i=1}^m g_i f_i=1.}
$$

- Common zero substituted into identity → $0=1$
- Boolean-variable constraints: $z_j^2-z_j=0$

**Example:** $f_1(z)=z$ and $f_2(z)=1-z$ cannot both vanish: they require $z=0$ and $z=1$. The identity $f_1+f_2=1$ certifies this directly, using $g_1=g_2=1$.

**Caveat:** potentially huge $g_i$ descriptions; certificate existence ≠ polynomial-size NP certificate

## Exponential time

$$
\mathrm E=\bigcup_{c\geq1}\mathrm{DTIME}(2^{cn}),\qquad
\mathrm{EXP}=\bigcup_{c\geq1}\mathrm{DTIME}(2^{n^c}).
$$

**E:** linear exponent. **EXP:** polynomial exponent

**NP simulation:** enumerate all length-$p(n)$ witnesses

$$
2^{p(n)}\operatorname{poly}(n)=2^{n^{O(1)}}.
$$

There are $2^{p(n)}$ candidate witnesses, each checked in polynomial time. Accept when one succeeds; reject after all fail. This gives a deterministic exponential-time decider for every NP language.

- $\mathrm P\subseteq\mathrm{NP}\subseteq\mathrm{EXP}$
- $2^{\sqrt n}$: superpolynomial; subexponential as $2^{o(n)}$
