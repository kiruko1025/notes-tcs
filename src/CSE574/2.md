## Reductions (Karp Reductions)

$$
L \le_p L' \iff \exists f: \Sigma^* \to \Sigma^* \text{ poly-time computable } : x \in L \iff f(x) \in L'
$$

### Example

$$
CLIQUE = \{<G,k>: G\text{ has a set} S \subseteq V(G) \text{s.t.} \forall u,v \in S:\{u,v\} \in E(G), |S|=k\}
$$

$$
CLIQUE \le_p INDSET
$$

## NP-complete

NP-complete problems are problems in NP that are as hard as any other problem in NP.

$L$ is NP-complete if $L \in NP$ and $\forall L' \in NP: L' \le_p L$

### Example 

$$
TMSAT = \{<M,x,1^n,1^t>:\exists u \in \Sigma^n \text{s.t. Turing Machine M accepts} <x,u> \text{in t steps} \}
$$

is in NP by simulation

$$
L \in NP \implies L \le_p TMSAT
$$

Given x, want to know if $x \in L$. L comes with a Turing Machine M s.t. $x \in L \iff \exists u \text{s.t.} M(x,u)=1$

## Cook-Levin Theorem

An interesting NP-complete problem called Boolean satisfiability (SAT).

Boolean Conjunctive Normal Form (CNF) (AND of ORs). 

Boolean variables $u_1, u_2,\dots,u_n \in \{0,1\}$

Literal: either $u_i$ or $\bar{u_i}$

CNF formula: $\wedge_i (\vee_j v_{ij})$ $v_{ij}$ either some $u_k$ or $\bar{u_k}$

$$
SAT = \{\phi : \phi \text{is a satisfiable CNF formula}\}
$$

$$
k-SAT = \{\phi : \phi \text{satisfiable k-CNF}\}
$$

Cook-Levin Theorem: $SAT$ is NP-complete.

### Proof

Idea: describe the run of a deterministic TM by a table (tableau) 

Table: the ith row describes the configuration(what's on tape, current state, head location) of the machine at time i (ith step)

Goal: Write down if M accepts $w_1,\dots,w_n$ as a CNF formula

Say I have a machine that runs in time $\leq n^k$ (n=length of the input). Look at $n^k \times n^k$ tableau.

Define Boolean variable $t_{ij\sigma }$ s.t. $t_{ij\sigma }=1$ if the cell in row i, column j of the tableau contains symbol $\sigma$.

#vars is $n^{2k} \cdot |S|, S= \{0,1\} \union Q \union \{\}$

Goal: write down same $\phi (t_{ij\sigma })$ s.t. $\phi $ evaluates to true iff the tableau describes an accepting run of M on $w_1,\dots,w_n$

Describe $\phi $ as a system of constraints:
$$
\phi = \phi_{cell} \wedge \phi_{start} \wedge \phi_{accept} \wedge \phi_{move}
$$

- $\phi_{cell}$: for each i,j, $t_{ij\sigma }$ is only one for precisely one choice of $\sigma $ (cell contains exactly one symbol)
- $\phi_{start}$: first row of tableau describes the valid start configuration of M on $w_1,\dots,w_n$
- $\phi_{accept}$: last row if accepting and rewinded
- $\phi_{move}$: for each i, the ith row of tableau describes a valid move of M from the (i-1)th row to the ith row

Cook-Levin reduction: 

- Given x, create $\phi $ based on M and its runtime. Hardwire x into $\phi $. So the only variable that remains to be found are the bits of u.
- Then I have $\phi $ that has a solution iff $M(x,u)=1$ has a solution for u.
