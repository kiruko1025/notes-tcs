# Lecture 5: Recursion and Evaluation Strategies

**Main ideas:** iteration carries state; self-application supplies recursion; evaluation strategy determines whether computation terminates. Encodings from [Lecture 4](4.md).

## Iteration with pairs

A Church numeral can repeat an update on an entire pair.

Read $n\,\mathsf{Step}\,\mathsf{Start}$ as “apply Step $n$ times, beginning at Start.” Start can be any encoded value. Keeping several intermediate results together lets each repetition access everything needed for the next update.

### Fibonacci

Keep consecutive values: $(a,b)\mapsto(b,a+b)$.

$$
\mathsf{FibStep}\triangleq
\lambda p.\mathsf{Pair}\;(\mathsf{Second}\;p)
\;(\mathsf{Add}\;(\mathsf{First}\;p)\;(\mathsf{Second}\;p)).
$$

$$
\mathsf{Fib}\triangleq\lambda n.\mathsf{First}\;
\bigl(n\;\mathsf{FibStep}\;(\mathsf{Pair}\;\overline0\;\overline1)\bigr).
$$

$$
(0,1)\mapsto(1,1)\mapsto(1,2)\mapsto(2,3)\mapsto(3,5)\mapsto\cdots
$$

After $n$ updates: $(F_n,F_{n+1})$. First component = answer; $F_0=0$, $F_1=1$.

**Pair invariant:** the next Fibonacci number needs both previous ones. The pair property holds initially and survives each update: $(F_k,F_{k+1})$ becomes $(F_{k+1},F_k+F_{k+1})$. An **invariant** is a property preserved by every update.

### Zero test and predecessor

$$
\mathsf{IsZero}\triangleq
\lambda n.n\;(\lambda u.\mathsf{False})\;\mathsf{True}.
$$

- Zero iterations: keep true.
- At least one iteration: return false.

The step function $\lambda u.\mathsf{False}$ ignores its input. The first repetition replaces the initial true with false; every later repetition returns false again. This detects zero through the numeral's behavior as an iterator.

For predecessor, remember the previous counter: $(a,b)\mapsto(b,b+1)$.

$$
\mathsf{PredStep}\triangleq
\lambda p.\mathsf{Pair}\;(\mathsf{Second}\;p)
\;(\mathsf{Succ}\;(\mathsf{Second}\;p)).
$$

$$
\mathsf{Pred}\triangleq\lambda n.\mathsf{First}\;
\bigl(n\;\mathsf{PredStep}\;(\mathsf{Pair}\;\overline0\;\overline0)\bigr).
$$

$$
(0,0)\mapsto(0,1)\mapsto(1,2)\mapsto(2,3)\mapsto\cdots
$$

$$
\mathsf{Pred}\;\overline n\to_\beta^*\overline{\max(n-1,0)}.
$$

**Pattern:** keep needed history in a pair; iterate an update; project the answer.

Predecessor uses the same trick: the second component counts upward; the first trails one update behind. Starting both at zero also handles $\mathsf{Pred}\;\overline0$ without negative numerals.

## Recursion as a fixed point

Separate one layer of factorial from its recursive calls:

Ordinary definition: $\operatorname{fact}(0)=1$; $\operatorname{fact}(n)=n\operatorname{fact}(n-1)$ for $n>0$. The parameter $r$ below stands in for the recursive name.

$$
T\triangleq\lambda r.\lambda n.
\mathsf{If}\;(\mathsf{IsZero}\;n)\;\overline1
\;(\mathsf{Mul}\;n\;(r\;(\mathsf{Pred}\;n))).
$$

- $r$: implementation of recursive calls.
- $T\,r$: one layer of factorial logic using $r$.
- Desired function: $\mathsf{Fact}=_\beta T\;\mathsf{Fact}$.
- **Fixed point:** unchanged by $T$ under beta convertibility; not literal equality of syntax.

Here $T$ takes a function as input and produces a function as output. A fixed point supplies the very function that its own recursive calls need. This turns the circular-looking equation into a construction problem: find a finite lambda term with that unfolding behavior.

### Curry's Y combinator

$$
Y\triangleq\lambda t.
(\lambda f.t\,(f\,f))\,(\lambda f.t\,(f\,f)).
$$

Let $A_t=\lambda f.t\,(f\,f)$, with $f$ fresh for $t$:

$$
\begin{aligned}
Y\,t&\to_\beta A_t\,A_t\to_\beta t\,(A_t\,A_t),\\
t\,(Y\,t)&\to_\beta t\,(A_t\,A_t).
\end{aligned}
$$

Same reduct, hence

$$
\boxed{Y\,t=_\beta t\,(Y\,t).}
$$

**Mechanism:** self-application recreates the term needed for the next recursive call. The boxed equation is convertibility, not generally one forward beta step.

In $A_t\,A_t$, substituting $A_t$ for $f$ turns $f\,f$ back into $A_t\,A_t$. Thus $t$ receives an expression that can supply another copy of the same computation whenever recursion needs it.

Set $\mathsf{Fact}=Y\,T$. Unfolding the recursive calls gives these beta-convertible expressions:

$$
\begin{aligned}
\mathsf{Fact}\;\overline3
&=_\beta\mathsf{Mul}\;\overline3\;
 (\mathsf{Mul}\;\overline2\;
  (\mathsf{Mul}\;\overline1\;\overline1))\\
&=_\beta\overline6.
\end{aligned}
$$

Inputs $3,2,1,0$; base case supplies $\overline1$. The equalities summarize recursion; actual evaluation also performs the encoded tests, predecessor calculations, and multiplications. Normal order reaches the normal form $\overline6$.

**No termination guarantee:** for $I=\lambda x.x$, $Y\,I=_\beta\Omega$ and normal-order evaluation diverges.

The combinator supplies recursion, not a reason for recursion to stop. Factorial terminates on natural-number inputs because each call decreases $n$ and the zero branch ends the recursion. An operator that always demands another recursive call has no such stopping point.

### A combinator with direct unfolding

$$
B\triangleq\lambda y.\lambda f.f\,(y\,y\,f),
\qquad \Theta\triangleq B\,B.
$$

$$
\Theta\,t
\to_\beta(\lambda f.f\,(B\,B\,f))\,t
\to_\beta t\,(B\,B\,t)=t\,(\Theta\,t).
$$

## Evaluation strategies

| Strategy | Next redex | Inside lambda bodies? |
| --- | --- | --- |
| Normal order | Leftmost outermost | Yes |
| Applicative order | Leftmost innermost | Yes |
| Call-by-name (CBN) | Function position; then substitute unevaluated argument | No |
| Call-by-value (CBV) | Function, then argument to a value, then apply | No |

- **Outermost:** outside every other redex.
- **Innermost:** contains no smaller redex.
- **Leftmost:** first eligible redex in left-to-right syntax order.
- **Weak evaluation:** no reduction under lambdas; values $v::=\lambda x.e$.

Example: $(\lambda x.I)\,\Omega$.

| Strategy | Behavior |
| --- | --- |
| Normal order / CBN | Discard unused argument; reach $I$ |
| Applicative order / CBV | Evaluate $\Omega$ first; loop |

**Normalization theorem:** if a beta normal form exists, normal order finds it. Confluence guarantees uniqueness, not successful evaluation under every strategy.

**Value versus normal form:** $\lambda x.\Omega$ is a value under CBN/CBV, but has no beta normal form.

A function can be ready to receive an argument even when its body would loop. Weak evaluation stops at that function; full normalization also tries to simplify its body. This explains the different stopping conditions.

| Argument handling | Tradeoff |
| --- | --- |
| CBN: substitute unevaluated argument | Avoid unused work; repeated uses may duplicate work |
| CBV: evaluate before substitution | Compute argument once; evaluate even unused arguments |
| Call-by-need: delay and share result | Avoid unused work and repeated argument evaluation |

## Making recursion work under CBV

Ordinary $Y$ unfolds $f\,f$ before passing it to $t$, causing endless recursive expansion.

**Fix:** delay self-application behind a lambda.

$$
Y_{\mathrm{cbv}}\triangleq\lambda t.
(\lambda f.t\,(\lambda z.f\,f\,z))
(\lambda f.t\,(\lambda z.f\,f\,z)).
$$

For a value $t$, define

$$
A=\lambda f.t\,(\lambda z.f\,f\,z),
\qquad R=\lambda z.A\,A\,z.
$$

$$
Y_{\mathrm{cbv}}\,t\to_{\mathrm{cbv}}A\,A
\to_{\mathrm{cbv}}t\,R.
$$

- $R$ already a value; body waits for an argument.
- Recursive call on value $v$: $R\,v\to_{\mathrm{cbv}}A\,A\,v\to_{\mathrm{cbv}}(t\,R)\,v$.
- Factorial also needs **delayed branches**, so the base case avoids recursion; completed in [Lecture 6](6.md).

The extra $\lambda z$ makes the recursive argument immediately acceptable to CBV as a value. The body $A\,A\,z$ is evaluated only when that function is called. For example, if $t=\lambda r.I$ ignores recursion, $Y_{\mathrm{cbv}}\,t$ can return $I$ immediately, while ordinary $Y\,t$ keeps trying to evaluate its recursive argument.
