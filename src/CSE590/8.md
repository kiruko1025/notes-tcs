# Lecture 8: Big-Step Semantics and Equivalence with Small-Step

**Main idea:** big-step semantics proves the result of a complete terminating computation. Also called **natural semantics**.

Small-step semantics asks what happens next; big-step semantics asks what the completed computation returns. The latter resembles a recursive interpreter: evaluate the parts, then combine their results. A big-step conclusion omits the intermediate configurations, but its proof still explains how the result was obtained.

## Judgments

| Judgment | Result |
| --- | --- |
| $\langle a,\sigma\rangle\Downarrow_a n$ | Arithmetic expression → integer |
| $\langle b,\sigma\rangle\Downarrow_b q$ | Boolean expression → truth value |
| $\langle c,\sigma\rangle\Downarrow\tau$ | Command → final state |

- State $\sigma:\mathrm{Var}\to\mathbb Z$; update $\sigma[x\mapsto n]$ changes only $x$.
- Expressions preserve state; commands may change it.
- Big-step command result = **state**, not a remaining command.
- Derivation = finite proof tree; may summarize any finite number of small steps, including zero.

Syntax and small-step rules: [Lecture 7](7.md).

**Reading a big-step rule:** to establish its conclusion, evaluate each premise and connect the results. A premise describes a complete subcomputation, so one proof tree can contain several loop iterations even though its conclusion gives only the final state.

## Expression rules

### Arithmetic

$$
\frac{}{\langle n,\sigma\rangle\Downarrow_a n}
\quad(\text{A-Num}),
\qquad
\frac{}{\langle x,\sigma\rangle\Downarrow_a\sigma(x)}
\quad(\text{A-Var}).
$$

For $\odot\in\{+,-,*\}$:

$$
\frac{
\langle a_1,\sigma\rangle\Downarrow_a n_1
\qquad\langle a_2,\sigma\rangle\Downarrow_a n_2
}{\langle a_1\odot a_2,\sigma\rangle\Downarrow_a n_3}
\quad(\text{A-Op}),
$$

where $n_3=n_1\odot n_2$ in $\mathbb Z$.

Both premises use the same state. Example: $\sigma(x)=4$ gives $\langle x+2,\sigma\rangle\Downarrow_a6$.

A-Num is a base case because a numeral already supplies its answer. A-Op recursively obtains two numerical answers before combining them. The rule does not return an unevaluated expression such as $4+2$; its result must be the numeral $6$.

### Booleans

$q,q_1,q_2\in\{\mathsf{true},\mathsf{false}\}$; $\bowtie\in\{=,\le\}$; $\diamond\in\{\land,\lor\}$.

$$
\frac{}{\langle q,\sigma\rangle\Downarrow_b q}
\quad(\text{B-Bool})
$$

$$
\frac{
\langle a_1,\sigma\rangle\Downarrow_a n_1
\qquad\langle a_2,\sigma\rangle\Downarrow_a n_2
}{\langle a_1\bowtie a_2,\sigma\rangle\Downarrow_b q}
\quad(\text{B-Compare})
$$

$q$ true exactly when the integer comparison holds; false otherwise.

$$
\frac{\langle b,\sigma\rangle\Downarrow_b q}
{\langle\neg b,\sigma\rangle\Downarrow_b\operatorname{not}(q)}
\quad(\text{B-Not})
$$

$$
\frac{
\langle b_1,\sigma\rangle\Downarrow_b q_1
\qquad\langle b_2,\sigma\rangle\Downarrow_b q_2
}{\langle b_1\diamond b_2,\sigma\rangle\Downarrow_b q}
\quad(\text{B-Op})
$$

$\operatorname{not}$ flips a Boolean; B-Op uses the ordinary truth table. **Strict convention:** both operands evaluated, matching Lecture 7.

All IMP expressions terminate with unique results: finite syntax, total states, total operations.

## Command rules

### Skip and assignment

$$
\frac{}{\langle\mathsf{skip},\sigma\rangle\Downarrow\sigma}
\quad(\text{Skip})
$$

$$
\frac{\langle a,\sigma\rangle\Downarrow_a n}
{\langle x:=a,\sigma\rangle\Downarrow\sigma[x\mapsto n]}
\quad(\text{Assign})
$$

Skip: unchanged state. Assignment: evaluate right-hand side in **old** state, then update.

### Sequence

$$
\frac{
\langle c_1,\sigma\rangle\Downarrow\rho
\qquad\langle c_2,\rho\rangle\Downarrow\tau
}{\langle c_1;c_2,\sigma\rangle\Downarrow\tau}
\quad(\text{Seq})
$$

Intermediate state $\rho$ connects the commands. Example: `x := 1; y := x + 2` finishes with $x=1,y=3$.

### Conditional

Abbreviate $\mathsf{if}\ b\ \mathsf{then}\ c_1\ \mathsf{else}\ c_2$ as $\mathsf{If}(b,c_1,c_2)$.

$$
\frac{
\langle b,\sigma\rangle\Downarrow_b\mathsf{true}
\qquad\langle c_1,\sigma\rangle\Downarrow\tau
}{\langle\mathsf{If}(b,c_1,c_2),\sigma\rangle\Downarrow\tau}
\quad(\text{If-True})
$$

$$
\frac{
\langle b,\sigma\rangle\Downarrow_b\mathsf{false}
\qquad\langle c_2,\sigma\rangle\Downarrow\tau
}{\langle\mathsf{If}(b,c_1,c_2),\sigma\rangle\Downarrow\tau}
\quad(\text{If-False})
$$

Only the selected branch needs a derivation; starts in $\sigma$.

The two conditional rules express control flow through different sets of premises. If the guard is true, no premise asks whether the else branch terminates. Thus a conditional can finish even if its unselected branch contains an infinite loop.

### While loop

Let $W=\mathsf{while}\ b\ \mathsf{do}\ c$.

$$
\frac{\langle b,\sigma\rangle\Downarrow_b\mathsf{false}}
{\langle W,\sigma\rangle\Downarrow\sigma}
\quad(\text{While-False})
$$

$$
\frac{
\begin{gathered}
\langle b,\sigma\rangle\Downarrow_b\mathsf{true}
\qquad\langle c,\sigma\rangle\Downarrow\rho\\
\langle W,\rho\rangle\Downarrow\tau
\end{gathered}
}{\langle W,\sigma\rangle\Downarrow\tau}
\quad(\text{While-True})
$$

| Case | Meaning |
| --- | --- |
| False | Zero body iterations; return current state |
| True | Run body; repeat original loop in updated state |

Recursive premise must have a **finite derivation**. Repeated syntax is allowed; circular proofs are not.

Follow the states: test in $\sigma$, run the body to obtain $\rho$, then restart the loop in $\rho$. The final state $\tau$ may differ from $\rho$ because further iterations can execute.

Using While-True does not assume that the loop finishes. It makes termination of the remaining loop an obligation that must itself be proved. In a finite derivation, this chain of remaining-loop premises must eventually end with While-False.

## Worked derivation: Euclid's algorithm

$$
B=\mathsf{If}(m\le n,\ n:=n-m,\ m:=m-n),
\qquad
W=\mathsf{while}\ \neg(m=n)\ \mathsf{do}\ B.
$$

Initial state: $\sigma_0(m)=6$, $\sigma_0(n)=4$; other variables $0$ in this example.

$$
\sigma_1=\sigma_0[m\mapsto2],
\qquad\sigma_2=\sigma_1[n\mapsto2].
$$

| State | $(m,n)$ | Guard $\neg(m=n)$ | Action |
| --- | --- | --- | --- |
| $\sigma_0$ | $(6,4)$ | true | $m:=6-4$ |
| $\sigma_1$ | $(2,4)$ | true | $n:=4-2$ |
| $\sigma_2$ | $(2,2)$ | false | Stop |

**First body:** variable lookup + subtraction + assignment + If-False.

The arithmetic premise below abbreviates two lookups, $\langle m,\sigma_0\rangle\Downarrow_a6$ and $\langle n,\sigma_0\rangle\Downarrow_a4$, followed by subtraction $6-4=2$. The assignment then changes only $m$; the false comparison selects that assignment.

$$
\frac{
\langle m\le n,\sigma_0\rangle\Downarrow_b\mathsf{false}
\qquad
\displaystyle\frac{\langle m-n,\sigma_0\rangle\Downarrow_a2}
{\langle m:=m-n,\sigma_0\rangle\Downarrow\sigma_1}
}{\langle B,\sigma_0\rangle\Downarrow\sigma_1}.
$$

Second body similarly: If-True gives $\langle B,\sigma_1\rangle\Downarrow\sigma_2$.

**Build the loop proof from its stopping case upward:**

| Judgment proved | Final rule | Required loop subtree |
| --- | --- | --- |
| $\langle W,\sigma_2\rangle\Downarrow\sigma_2$ | While-False | None |
| $\langle W,\sigma_1\rangle\Downarrow\sigma_2$ | While-True | Previous row |
| $\langle W,\sigma_0\rangle\Downarrow\sigma_2$ | While-True | Previous row |

Execution runs from $\sigma_0$ toward $\sigma_2$. Proof assembly works backward from the stopping case: a completed proof of the remaining loop supplies the premise needed for the preceding iteration.

Top-level rule instance:

$$
\frac{
\begin{gathered}
\langle\neg(m=n),\sigma_0\rangle\Downarrow_b\mathsf{true}
\qquad\langle B,\sigma_0\rangle\Downarrow\sigma_1\\
\langle W,\sigma_1\rangle\Downarrow\sigma_2
\end{gathered}
}{\langle W,\sigma_0\rangle\Downarrow\sigma_2}.
$$

Result: entire state $\sigma_2$; $m=n=2$, other variables unchanged. General termination argument for positive inputs: [Lecture 7](7.md#euclids_subtraction_algorithm).

## Divergence and determinism

$W_\infty=\mathsf{while}\ \mathsf{true}\ \mathsf{do}\ \mathsf{skip}$ has **no finite big-step derivation**.

Proof by contradiction:

1. Choose a derivation of $\langle W_\infty,\sigma\rangle\Downarrow\tau$ with minimum height.
2. Last rule must be While-True; skip leaves state $\sigma$.
3. Recursive premise proves the same judgment with smaller height: contradiction.

This argues about the existence of any finite proof, not just one unsuccessful attempt to construct it. Proof heights are natural numbers, so they cannot decrease forever. The absence of an applicable stopping rule for this loop prevents every possible finite derivation.

Small-step semantics instead shows an infinite run. In this IMP, nonterminal configurations cannot get stuck, so absence of a big-step result means divergence. With runtime errors, absence alone could also mean stuckness.

**Determinism:**

$$
\langle c,\sigma\rangle\Downarrow\tau_1
\land\langle c,\sigma\rangle\Downarrow\tau_2
\Longrightarrow\tau_1=\tau_2.
$$

Proof outline: rule induction on the first derivation; keep the second result arbitrary. Expression results fix branch choices; IHs identify intermediate states, then final states.

For Seq, compare both derivations of $c_1$ first: their intermediate states must agree. Only then compare the derivations of $c_2$, which now have the same starting state.

$$
\operatorname{eval}:\mathrm{Com}\times\Sigma\rightharpoonup\Sigma.
$$

**Partial function:** at most one result; loops may prevent any result. Determinism does not imply termination.

## Connection to small-step semantics

$$
\boxed{
\langle c,\sigma\rangle\Downarrow\tau
\iff
\langle c,\sigma\rangle\to^*\langle\mathsf{skip},\tau\rangle.
}
$$

| Direction | Proof method |
| --- | --- |
| Big-step → finite small-step run | Rule induction; lift subruns; concatenate |
| Finite small-step run → big-step | Induct on run; reconstruct earlier result using anti-reduction |

- Same terminating programs and final states.
- Skip's big-step axiom corresponds to **zero** small steps.
- Proof depends on expression correspondence and matching intermediate states.
- Full proof outline and lemmas: [Lecture 9](9.md).

The equivalence lets us choose the most useful representation for a task. Small steps expose evaluation order and infinite runs; big-step trees organize reasoning about completed subcomputations. Agreement on final states means that switching between them does not change the answer for a terminating program.
