## Functions 
Takes input produce output always return consistently

Relation: A relation R between A,B $R \subseteq A\times B$

A fucntion $f:A\to B$ is a relation $f \subseteq A\times B$, $\forall x \in A \exists !b \in B, (a.b) \in f$

Graph/extension: (x,f(x))

## (Untyped)Lambda-calculus

### $\Lambda $-term:

- fix set $V$ (countably infinite)
- $x \in V$ (variable)
- if e is $\Lambda $-term $x \in V$ $\Lambda x.e$ is $\Lambda $-term (abstraction) (f(x)=e)
- if e1,e2 are $\Lambda $-term $e1 e2$ is. ($e_1(e_2)$)

$\Lambda x.e_1e_2$ is $\Lambda x(e_1e_2)$
$e_1e_2e_3$ is $((e_1e_2)e_3)$

### Properties

identity - $\Lambda x.x$
second - $\Lambda x.\Lambda y.y$ (currying)
application - $\Lambda f.\Lambda x.fx$

Syntactic (expression):
$e::=x|e_1e_2|\Lambda x.e$
x,e: metavariables

### $\beta $ reduction

$(\Lambda x.e_1)e_2$ -> $e_1[e_2 \to x]$ -> substitute e2 for x in e1

Example:
$(\Lambda x.(\Lambda z.x))z$ -> $(\Lambda z.z)$

The letter after lambda is bindins site

Nominal - using V fir names - $\Lambda f.\Lambda x.\Lambda y(fx)(fy)$

Nameless:

- de Bruijn indices- $\Lambda \Lambda \Lambda (21)(20)$
- de Bruijn levels - $\Lambda \Lambda \Lambda (01)(02)$
